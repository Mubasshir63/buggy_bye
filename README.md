# BugHunter AI

**Early Access v1.0.0**

Local AI-powered Python debugging assistant using Ollama, LangGraph and MARGINAL governance.

## Features
- Pytest failure analysis
- Local LLM repair proposals
- Governed repair authorization
- Automatic source backups
- Post-repair verification
- Rollback workflow

## Requirements
- Python 3.12
- Ollama
- Qwen 2.5 Coder 3B

## Run
Set BUGHUNTER_PROJECT to your target project directory, then run:
python agent_graph.py

## Limitations
Early Access prototype. Limited Python project support. Review all AI-generated changes. MARGINAL is not an operating-system sandbox.
